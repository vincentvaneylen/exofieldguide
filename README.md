# Exoplanet Field Guide

What would you see if you stood on a planet round another star? This guide draws views of real exoplanets from what telescopes have measured. Where the measurements stop, it says so, shows each world the planet could be, and marks what is imagined.

- Planet data: [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu)
- Literature context: papers found through [SciX/ADS](https://scixplorer.org), summarised and checked against the archive values
- "How a picture is made" (`recipe.html`) explains every step from measurement to picture

It is a static site with no build step or server: open `index.html`, or serve the folder with any web server.
